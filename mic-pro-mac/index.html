从记录生活，
到接进我的 Mac 工作流。

我一直想有一支能随身记录生活的录音笔，把对话与灵感留下来，让 Agent 更了解我的上下文。Mic Pro 的腾讯会议版本把录音接进腾讯会议录音笔，这条链路吸引我买下了它。

后来，我希望它也进入 Vibe coding 工作流。蓝牙收音已经能用，但我想独立安排输入和输出，顺手管理连接与设备状态，于是研究蓝牙与 USB 通信，做出这个原生 Mac 面板。腾讯会议的上传链路由设备与腾讯会议完成；这个工具负责 Mac 上的设备操作与本地录音管理。

开发预览版的边界

  • 核心功能在一台 Mic Pro TX、固件 2.0.2.4 上实机验证。
  • 更多设备与固件仍需要测试；公开版提供显式设备配置。
  • 供电标志不独立识别充电暂停；满电接线显示“已接电源”。
  • 震动提示通过短暂切换降噪并恢复实现；没有独立马达或任意灯色控制。

从源码开始。

需要 macOS、Xcode Command Line Tools 和 Python 3。首次使用先配置自己的已配对设备。Codex 额度与实验性控制默认关闭。
