从“想看一眼电量”
做成一个开源小工具。

Mac 的蓝牙面板能显示电量，但桌面上还缺少一个顺手的设备入口。我从公开的协议研究开始，写出 Swift 控制逻辑，再回到自己的 Mic Pro 上逐项验证。

充电状态做过插线、拔线、重插对照；壁纸写入前做完整备份，完成后读回校验。交互中也保留忙碌、未知和失败状态。

开发预览版的边界

  • 核心功能在一台 Mic Pro TX、固件 2.0.2.4 上实机验证。
  • 更多设备与固件仍需要测试；公开版提供显式设备配置。
  • 供电标志不独立识别充电暂停；满电接线显示“已接电源”。
  • 震动提示通过短暂切换降噪并恢复实现；没有独立马达或任意灯色控制。

从源码开始。

需要 macOS、Xcode Command Line Tools 和 Python 3。首次使用先配置自己的已配对设备。Codex 额度与实验性控制默认关闭。
